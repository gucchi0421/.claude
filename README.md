# Claude Code 個人設定リポジトリ

Claude Code の設定・エージェント・スキル・スクリプトを管理する dotfiles パッケージ。
`~/.claude/` へシンボリックリンクを貼ることで全環境に反映される。

## 構成

```
.claude/
├── agents/          # サブエージェント定義
├── skills/          # スキル（スラッシュコマンド）定義
├── scripts/         # 自動化スクリプト
├── rules/           # ルール・ペルソナ・ワークフロー定義
│   ├── _core/       # ペルソナ・出力形式・セキュリティ等
│   ├── tools/       # 外部ツール連携（Codex・Gemini等）
│   └── workflows/   # 作業フロー（記事作成・Gitなど）
├── CLAUDE.md        # グローバル設定のエントリポイント
└── settings.json    # Claude Code 設定ファイル
```

## セットアップ

```sh
# dotfiles リポジトリから
make add pkg=claude
```

これで `~/.claude/` → `~/documents/dotfiles/packages/claude/.claude/` のリンクが貼られる。

## 今後の展望

### SNS 運用自動化（Claude Code Company）

Claude Code 上に「インスタ運用会社」を構築する仕組みを導入予定。  
`cc-company` プラグイン（`Shin-sibainu/cc-company`）をベースに、以下の部署をサブエージェントとして編成する。

| 部署 | 役割 |
|---|---|
| 秘書 | ヒアリング・タスク管理・日次まとめ |
| リサーチ部 | 競合分析・バズ投稿収集・トレンド調査 |
| クリエイティブ部 | フィード投稿・リール台本・キャプション生成 |
| コミュニティ部 | コメント文・DM文案の一括生成 |
| マーケティング部 | Instagram→LINE 導線設計・ステップ配信シナリオ |
| プロダクト部 | PDF教材・テンプレート等の商品企画・制作 |

スキルで毎日の定型作業（投稿ネタ出し・コメント文生成・週次レポート等）を自動化し、  
`/skill 週次投稿ネタ出し` のような一発呼び出しで運用を回す設計を目指す。

### AI 最新情報キャッチアップ自動化（ut-ai-news-report の拡張）

現在の `ut-ai-news-report` スキル（Web記事4サイトを毎日収集→Chatwork送信）を拡張し、  
**YouTube の最新動画も含めた自分専用のキャッチアップ記事**を自動生成する仕組みを構築予定。

「見るだけで最新を追える」をゴールに、記事・動画を横断して1本にまとめる。

**処理フロー**

```
【Web記事収集】                    【YouTube動画収集】
ledge.ai / ai-news.dev 等          指定キーワードで YouTube 検索
Web記事を取得・分類                 最新動画を取得（Shorts除外）
        ↓                                  ↓
        ↓         字幕取得（yt-dlp）        ↓
        └──────────────────────────────────┘
                          ↓
              Claude で統合要約・記事生成
              （記事トピック × 動画解説を紐付け）
                          ↓
              自分専用キャッチアップ記事として保存 / 送信
```

**キャッチアップ記事の構成イメージ**

```
📰 YYYY-MM-DD AI最新まとめ

## 今日のハイライト
（全体を3行で要約）

## トピック別まとめ
### リリース・アップデート
  - [記事] タイトル——要約
  - [動画] チャンネル名「動画タイトル」——要約

### 技術・研究 / ビジネス / 政策 …
  （同形式）
```

**技術スタック（予定）**

- yt-dlp（YouTube字幕・メタデータ取得、Shorts除外）
- Claude API（記事・動画の統合要約）
- 既存の `/chatwork` スキル経由で Chatwork に送信、またはローカルファイルに保存
- GitHub Actions または ローカル cron（定期実行）

**既存スキルとの関係**

| 現状 | 拡張後 |
|---|---|
| Web記事のみ収集 | Web記事 + YouTube動画を横断収集 |
| カテゴリ別に箇条書き | トピックに記事と動画を紐付けて1本化 |
| Chatwork に送信 | Chatwork 送信 + ローカル保存（見返し可能） |
