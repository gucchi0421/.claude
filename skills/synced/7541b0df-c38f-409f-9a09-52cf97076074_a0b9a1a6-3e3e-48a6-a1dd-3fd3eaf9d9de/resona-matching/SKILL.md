# りそな振替照合スキル

## 概要

りそな銀行の口座振替一覧PDF（月次）と請求書PDF群を突合し、
入金金額と請求金額の差異を検出・レポート出力する月次照合ワークフロー。

---

## ディレクトリ構成の前提

```
作業フォルダ/
└── YYYY年M月/          ← 対象月フォルダ（当月実行なら前月が対象）
    ├── りそな振替一覧_YYYYMM.pdf    ← 振替一覧PDF（1ファイル）
    └── invoices/                    ← 請求書PDFフォルダ
        ├── 20240301-0001U.pdf
        ├── 20240301-0002U.pdf
        └── ...
```

> **対象月の決定ルール**  
> スクリプト実行時点の「前月」が照合対象となる。  
> 例：4月実行 → 3月分（`YYYY年3月/`）を処理する。

---

## ステップ別実行手順

### Step 1 : 対象フォルダの特定

```python
# scripts/detect_target_folder.py を参照
```

- 実行月から前月を算出し、`{YYYY}年{M}月` パターンでフォルダを検索する
- 見つからない場合はユーザーにパスを問い合わせる

### Step 2 : りそな振替一覧PDFの解析

抽出対象列：

| 列名 | 説明 | キーとして使用 |
|------|------|--------------|
| 顧客番号 | 銀行側の顧客番号（N桁） | 下4桁を使用 |
| 預金者名 | 口座名義 | 参照のみ |
| 入金金額 | 実際の振替金額（税込） | 照合対象 |

> **注意**  
> りそなPDFはレイアウト型PDFのため `pdfplumber` による列抽出を優先する。  
> 抽出失敗時は `pdftoppm` でラスタライズして視覚確認へフォールバックする。  
> 詳細は `references/pdf_extraction.md` を参照。

### Step 3 : 請求書PDFのスキャンと照合キー抽出

ファイル名規則：

```
{Ymd}-{NNNN}U.pdf
例: 20240301-0001U.pdf → 照合キー = 0001
```

- ファイル名から `{NNNN}` 部分（下4桁）を正規表現で抽出する
- ファイル名規則に合致しないファイルはスキップし、スキップ一覧をレポートに記録する

### Step 4 : 金額照合ロジック

照合キー（下4桁）をもとに突合し、以下のケースをすべて記録する：

| ケース | 分類 |
|-------|------|
| 入金あり・請求書あり・金額一致 | ✅ 正常 |
| 入金あり・請求書あり・金額不一致 | ⚠️ 差異あり |
| 入金あり・請求書なし | ❓ 請求書なし |
| 入金なし・請求書あり | 🔴 未入金 |

> **照合キーの優先順位**  
> 預金者名とクライアント名が異なる場合がある。  
> **顧客番号下4桁を正** として照合し、名称は参照のみとする。

### Step 5 : レポート出力

出力フォーマット（Markdown表）：

```
| 顧客番号下4桁 | 預金者名 | 入金金額 | 請求書ファイル | 請求金額 | 差異 | ステータス |
|-------------|---------|---------|-------------|---------|-----|---------|
| 0001 | ○○○○ | 10,000 | 20240301-0001U.pdf | 10,000 | なし | ✅ |
| 0002 | △△△△ | 20,000 | 20240301-0002U.pdf | 25,000 | ▲5,000 | ⚠️ |
| 0003 | □□□□ | 15,000 | （なし） | - | - | ❓ |
| - | - | - | 20240301-0099U.pdf | 8,000 | - | 🔴 |
| | | **合計** | | **合計** | | |
```

## スクリプト実行

自動化スクリプト群は `scripts/` に配置する。  
詳細な実装は `scripts/match.py` を参照。

```bash
# 実行例（前月を自動検出）
python scripts/match.py --base-dir /path/to/作業フォルダ

# 対象月を明示する場合
python scripts/match.py --base-dir /path/to/作業フォルダ --year 2024 --month 3
```

## エラーハンドリング一覧

| エラー種別 | 対処 |
|-----------|------|
| PDFが読み取れない（破損・パスワード保護） | 該当ファイル名をレポートのエラー欄に記録してスキップ |
| ファイル名が命名規則と異なる | スキップして「形式不正ファイル一覧」に記録 |
| 対象月フォルダが存在しない | ユーザーにパスを問い合わせ |
| 振替一覧PDFが複数存在する | ファイル一覧を提示してユーザーに選択を促す |
| 金額フィールドの文字化け | ラスタライズ（`pdftoppm`）にフォールバックして視覚抽出 |
